Co-founder & CEO of [Scrub AI](https://scrub-ai.com). We turn the messy data commercial insurance runs on
(SOVs, bordereaux, schedules) into clean, model-ready data for insurers, MGAs and brokers in the London Market.

I spent six years in product roles at Thermo Fisher Scientific, automating the work around me with code,
before co-founding Scrub in 2020, and I still care about how things are built. Our stack is Python and
Rust, and where our work touches open-source tooling, we contribute back:

- [ruff](https://github.com/astral-sh/ruff/commits?author=Alex-ley-scrub) · Python linter and formatter (Rust)
- [gritql](https://github.com/biomejs/gritql/commits?author=Alex-ley-scrub) · code search and rewriting (Rust)
- [calamine](https://github.com/tafia/calamine/commits?author=Alex-ley-scrub) · Excel reader (Rust)
- [openpyxl](https://foss.heptapod.net/openpyxl/openpyxl/-/blob/branch/default/AUTHORS.rst?plain=1#L14) · Excel library (Python)
- [aws-billing-to-slack](https://github.com/iandees/aws-billing-to-slack/commits?author=Alex-ley) · AWS to Slack (Python)
- [many more](https://github.com/orgs/Scrub-AI/repositories?q=fork%3Atrue) · SSF, Flask Swagger, etc. (mostly Python)

Engineers who want to work on hard, real-world data problems:
[get in touch](https://scrub-ai.com/contact-us/).
